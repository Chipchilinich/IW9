# Проект разработки сервиса трекера полезных привычек с помощью Django REST Framework ^_^
## В данном проекте реализован функционал backend части приложения для создания привычек и их интеграции с Телеграм Ботом, который реализует отправку напоминания пользователю о его привычке.

### Реализована модель Привычки и Пользователя и соответствующие к ним контроллеры и сериализаторы, создана отложенная задача для отправки напоминаний через интеграцию с Telegram API.


## Установка:
1. Убедитесь, что у вас установлен Poetry. Если нет, вы можете установить его, следуя официальной документации.
2. Клонируйте репозиторий через ssh: 
```
git@github.com:Chipchilinich/IW9.git
```
3. Устанавливайте зависимости из файла **pyproject.toml** командой: 
```
poetry install
```

## Использование:
Проект на стадии разработки, для запуска приложения используется docker-compose. Приложения собраны в контейнеры, конфигурация находится в файле: ```docker-compose.yml```

Запустить можно через команду:
```
docker-compose up
```
Или протестировать работоспособность можно локально через терминал, запустив:
```
python manage.py runserver
```
